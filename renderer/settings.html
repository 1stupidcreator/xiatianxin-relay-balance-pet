账号余额桌宠

API Key 只保存在本机。所有功能均可随时开关。

账户

填站点根地址（不带 /v1）。余额口径：Key 设额度→Key 额度剩余；设限速→限额剩余；都不设→钱包余额。统计窗口会标注。
填写后自动登录面板（JWT），「今日已用」和 24 小时统计将显示账号级真实消耗（实际扣除，跨全部 Key）；留空则用本地余额差值估算。密码仅保存在本机 config.json。
网页登录后按账号 Key 自动匹配；也可按住 Ctrl 多选。每个分组只能归一个账号。所有已绑定账号每分钟独立检查，显示哪个账号都不影响告警；未绑定时不冒用其他账号的数据。
官方 DeepSeek 留空即可；第三方兼容服务填它的余额接口地址。
每多少秒自动刷新余额，默认 30；填 0 关闭自动刷新。每次刷新都会计入 24 小时统计采样。

提醒与统计

默认每 10 个账户货币单位提醒一次（10、20、30…），金额单位与「今日已用」一致，不换算汇率。仅使用账号登录后的实际消费；需开启记录今日消耗。启动或改阈值不补报旧节点，同一节点不重复提醒。一次刷新跨多个节点时只提醒一次。
% 时提醒
缓存告警通过 Windows 通知显示缓存率、阈值、取样时间、请求数，以及缓存读取、写入、未缓存和总输入 Token。点击通知可打开统计页。
开启后，每分钟检查本机 Codex 代理最近 60 秒的缓存率；低于 80% 时发送 Windows 通知，持续偏低每分钟提醒一次，同一检查分钟不重复通知。缓存率按有效输入 Token 加权，失败请求及未知或异常口径计入排除数；无有效用量或样本口径不完整时不告警。统计页另显示最近 1 小时数据，JWT 账号历史统计保持独立。
