# 账号余额桌宠 · Relay Balance Pet

一款面向 Windows 的 Electron 桌宠，在桌面显示账号余额与今日已用，并提供账号历史用量、本机 CC Switch 缓存统计和提醒。

桌宠使用透明女性立绘与气泡，应用及托盘图标沿用同一人物。桌宠窗口不占任务栏，设置和统计从托盘打开。

![桌宠外观](docs/pet-preview.png)

> 图片使用虚构演示金额，不代表任何真实账户。

## 功能

- **余额与今日已用**：支持 Sub2API 兼容站点和 DeepSeek 模式。Sub2API 站点地址与 API Key 由使用者填写，初始值为空。
- **账号历史统计**：配置面板登录账号后，查看最近 24、72、144 小时的消费、请求、Token 和缓存数据。
- **本机缓存统计**：读取 CC Switch 的 Codex 代理日志，分别显示最近 1 分钟和 1 小时的缓存率、有效请求数与 Token 构成。
- **缓存提醒**：每分钟读取新样本，最近 1 分钟缓存率低于 80% 时发送 Windows 通知，并可播放系统提示音。
- **暂停读取**：在设置中暂停 CC Switch 统计 1–168 小时，或立即恢复。暂停期间不读取该数据库，也不发送缓存告警；JWT 账号统计照常使用。
- **消费节点提醒**：按可调金额阈值跳动、发声，默认间隔为 10 个账号货币单位；普通扣费不逐笔发声。
- **桌面操作**：悬停高亮、移出变淡，人物右键隐藏 10 秒，支持手动隐身、位置锁定、贴边、多显示器与开机自启。
- **可选 Webhook**：按设置向使用者指定的 URL 发送低余额事件或测试消息，默认关闭。

## 快速开始

### 下载 Windows 便携版

在 [GitHub Releases](https://github.com/1stupidcreator/xiatianxin-relay-balance-pet/releases) 下载 `Relay-Balance-Pet-*-portable.exe`，双击即可运行，无需安装 Node.js。发布页同时提供源码 ZIP 和 `SHA256SUMS.txt`，可用 PowerShell 的 `Get-FileHash -Algorithm SHA256` 核对下载文件。

### 从源码运行

需要 Windows 和 Node.js 22.13 或更新版本。Node.js 必须提供 `node:sqlite`，本机缓存统计依赖该模块。

```powershell
npm ci
npm start
```

完成依赖安装后，也可以双击项目根目录的 `start-pet.vbs` 启动。该入口不显示终端窗口，适合日常使用。

首次启动后，右键系统托盘图标打开 **设置**：

1. 选择站点类型。Sub2API 模式填写自己的站点根地址和 API Key；DeepSeek 模式填写对应 API Key。
2. 如需账号级今日已用和历史统计，填写该 Sub2API 面板的登录账号与密码，并开启统计。
3. 如需本机缓存统计，确保 CC Switch 正在记录 Codex 代理请求。统计页会显示数据库缺失、结构不兼容或数据口径不完整等状态。
4. 按需调整提醒、刷新间隔、外观、隐身与开机自启。设置更改会自动保存。

不同 Sub2API 部署的接口可能存在差异。本项目使用 `/v1/usage` 读取余额，使用面板登录与小时用量接口读取账号历史；仅支持与这些接口兼容的部署。

### 构建 Windows 便携版

```powershell
npm ci
npm run dist:win
```

输出位于 `dist/`。构建与依赖安装可能需要下载 Electron 及打包工具。

### 日常操作

| 操作 | 结果 |
| --- | --- |
| 单击桌宠 | 刷新余额 |
| 右键人物 | 隐藏 10 秒后恢复；手动隐身或全屏隐身仍有效 |
| 右键托盘 | 打开刷新、使用与缓存统计、设置、退出菜单 |

## 统计口径与刷新

### 账号历史与今日已用

Sub2API 面板登录成功后，今日已用优先采用账号实际扣费，历史统计采用服务器返回的小时数据。它们反映账号范围内的用量，不限于当前余额查询使用的单个 API Key。

未配置面板登录时，程序可以根据本机余额变化估算今日已用；该估算会受充值、退款和采样间隔影响。界面会区分账号数据、本机估算与待更新状态。服务端数据暂时失败时，不根据过期值触发消费节点提醒。

消费节点按当天金额递增。例如阈值为 10 时，在达到 10、20、30 等节点时提醒；同一节点不重复提醒，单次刷新跨过多个节点合并为一次。启动、重新启用或改变阈值时不补报已有消费，跨天重新计数。

JWT 历史缓存率按 Token 总量加权：

```text
缓存率 = 缓存读取 Token ÷（未缓存输入 Token + 缓存写入 Token + 缓存读取 Token）
```

### CC Switch 最近 1 分钟与 1 小时

数据库位置为 `%USERPROFILE%\.cc-switch\cc-switch.db`，仅以只读方式打开，不修改 CC Switch 的数据库、供应商配置或凭据。

仅纳入 `app_type=codex`、`data_source=proxy`、HTTP 200–299、已验证 Token 语义的有效代理日志。其他应用、导入的会话历史、失败请求、未来记录与非法用量不混入统计。请求写入日志后才可见，进行中的请求尚未计入。

对于 `input_token_semantics=1` 的记录，输入总量已包含缓存读取与写入，因此公式为：

```text
缓存率 = SUM(cache_read_tokens) ÷ SUM(input_tokens)
```

不再将缓存 Token 重复加到分母，也不平均每条请求的百分比。输出 Token 不参与缓存率计算。未知语义或异常成功用量会使对应窗口标记为口径不完整，并停止该窗口的缓存率告警；没有有效输入 Token 时不会把缓存率当作 0%。

统计页每 30 秒刷新显示，自动读取可复用不超过 30 秒、带采样时间的快照。**手动刷新和每分钟告警强制读取新样本**；立即恢复读取时也会重新采样。这些数据只代表本机 CC Switch Codex 代理范围，与 JWT 账号历史的范围不同。

### 缓存告警

开启后，每分钟检查最近 60 秒的有效数据。缓存率 **低于 80%** 才告警，恰好 80% 不告警；持续偏低最多每分钟提醒一次，同一检查分钟去重。

通知包含采样区间、有效请求数以及缓存读取、写入、未缓存和总输入 Token，点击通知可打开统计页。没有有效数据、数据口径不完整、读取失败或暂停读取时不告警，不补发旧窗口的提醒。

Windows 通知权限、免打扰和系统音量会影响通知及声音呈现。设置中的缓存告警声音与消费节点声音独立控制。

## 配置与隐私

运行数据保存在 `%APPDATA%\relay-balance-pet\`，包括配置、余额采样、提醒去重状态与诊断日志。源码仓库不包含使用者的运行配置和历史数据。

| 数据 | 存储与用途 |
| --- | --- |
| 站点地址、API Key、面板账号与密码 | 保存在本机 `config.json`，用于连接所选服务；JSON 中的凭据未加密 |
| JWT 登录 Token | 仅保存在运行进程内存中，按有效期更新；认证失败会显示状态 |
| 余额采样与提醒状态 | 保存在本机，用于统计显示和重复提醒控制 |
| CC Switch 用量 | 从本机数据库只读查询，用于最近 1 分钟、1 小时统计和缓存告警 |
| Webhook | 默认关闭；开启后向使用者填写的 URL 发送事件与余额等数据 |

Sub2API 请求发往设置中填写的站点；DeepSeek 模式使用其余额 API；可选 Webhook 请求发往设置中指定的目标。配置中的 API Key 用于对应服务的认证，面板账号与密码用于该站点登录。

分享源码或提交 Git 前，请保留仓库的忽略规则，不将个人配置、运行日志、余额历史、截图中的真实账号数据或凭据加入版本控制。
